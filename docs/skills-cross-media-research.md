# 跨媒介名场面招式调研（X25 候选池）

2026-10-29。用户要求：新招式不再局限《蛊真人》，从动漫、影视、游戏的名场面里取材。

## 1. 结论先说

- **值得做，而且大部分不用花积分。** 现有 29 招（9 被动 + 20 主动）的引擎原语已经覆盖名场面的三分之二：多段、定身 / 眩晕 / 入梦、致盲、替身、封招、反弹、吸血、召唤、回旋、减速、必中。真正缺的只有三种节奏：**蓄力**、**领域**、**瞬影**。
- 首批建议 6 招，素材约 **54–60 积分**（只有`鲸派气功`要新动作素材，其余复用现有动作 + 一两张贴图）：
  `鲸派气功`（蓄力光炮）、`深渊领域`（领域）、`瞬影`（闪避 + 必中）、`鲸拳乱打`（多段）、`电鳗贯体`（麻痹）、`认真一拳`（必中高伤）。
- 名字走**修仙化改造**（图鉴里注明致敬出处），世界内自洽；想直接用原名，改 `SKILLS` 里的一行字符串就行。
- 世界观上给个说法：`前有古人` 已经开了「光阴长河」的口子，这批招式统一记成**「梦里见过的别界杀招」**——宠物入梦看见别的世界，醒来照着打出来，图鉴里写「梦中得授」。

## 2. 口径

**怎么挑**（五条，全中才进推荐池）：

1. **三秒认得出**：只看动作和特效就知道是哪一招，不靠台词解释。
2. **能落到现有原语上**：优先零引擎改动，其次加一两个状态位；不为单招造大系统。
3. **不和现役 29 招撞**：撞了就换角度（比如反弹已有`逆流护身印`，弹反就先不进首批）。
4. **640×360 画得出来**：舞台就那么大，大场面靠**全屏叠加的特效层**，不指望动作素材里画出全景。
5. **素材能复用就复用**：动作素材 24 积分一段，贴图 6 积分一张；能复用`战斗-直拳 / 连拳 / 闪避 / 出手-护身印 / 出手-万我`的，成本压到 0–6。

**三条红线**：

- 不破坏切磋平衡：新主动招都是「一场一次」，但每加一门就抬高一局的总爆发，必须跑 `battle-sim.mjs` 看胜率表（X16 扩到 19 门时调过一次）。
- 不碰对战规则：`BATTLE_VERSION` 只在结算规则变时 +1；纯加招不动它，但**名帖里旧版本的对方认不出新招式 id**，要确认握手逻辑（`z.enum(SKILL_IDS)` 会随枚举扩展，旧存档没问题，旧对端有问题）。
- 招式名做改造，出处写图鉴。原作名直接当招式名会显得像搬运；`鲸派气功`、`认真一拳`这种带梗的保留原名也行，是一行数据的事。

## 4. 引擎增量

三个状态位，都只影响自己那一手，不碰结算主流程：

| 原语 | 状态 | 规则 | 用法 |
| --- | --- | --- | --- |
| 蓄力 | `me.charge` | 出招这一拍置位：本拍不攻击、挨打减伤 30%；下一拍自动放必中大伤，放完清位 | 鲸派气功、元气弹、Excalibur 一类 |
| 领域 | `me.field` | 置位后 2 拍：对方不能闪避 / 替挡，每拍开头结算 4–6 伤 | 深渊领域 |
| 瞬影 | `me.blink` | 置位后：本拍挨打按闪避算（不结算、不判必中），下一拍攻击必中 | 瞬影 |

演出层复用 X24 的 `hold`（静止贴图）+ 现有 `line / arc / slam / thrust` 轨迹，不需要新轨迹：

- 蓄力：两段动作（聚气 → 推出），中间夹一张随时间变大的光球（`grow` 已有）。
- 领域：一张全舞台的符阵（`hold`，`anchor: 'mid'`，尺寸按舞台高 ×1.2）+ 一层黑雾（`hold`，低透明度，淡出更慢）。
- 瞬影：残影用 `hold` 铺在原地 200ms 后淡出；人靠素材自己闪。
- 延迟受击：北斗百裂拳那类，结算不变，只是把受击动画的 `at` 往后挪一拍（时间线本来就按绝对时刻排）。

| 招式 | 数值草案 | 分镜 | AI 触发 | 素材 |

| 电鳗贯体 | 24–30 + 30% 麻痹一拍 | 抬手 → 电弧从鳞片炸出 → 对方僵一下 | 对方没在控制状态 | 0–1 张 |

**排期**：引擎三原语 + 六招数据 + AI 条件（1 天）→ 时间线与演出（1 天）→ 素材生成与抠像（半天）→ `fx-preview` 逐帧核 + `battle-sim` 调胜率（1 天）。

**验收**：prettier / typecheck / lint / `npm test` 全过；`battle-sim.mjs` 胜率表在 ±5% 内；`fx-preview` 六场重录逐帧核（蓄力两拍接得上、领域盖满舞台但看得见两只、瞬影残影不糊脸、认真一拳背景裂开）。

## 6. 备选与第二批（X26，先不排）

`月牙天冲`、`千鸟·雷切`、`螺旋丸`、`北斗百裂拳`、`弹反`、`子弹时间` 六个。这一批以「远程斩」「冲刺穿刺」「延迟受击演出」为主，引擎上不需要新原语，主要是素材和编排。北斗百裂拳的「你已经死了」是全表里最值得做的一记情绪点。

## 7. 实现注意

- **技能池膨胀**：主动招都是一场一次，加到 26 门后一局的总爆发明显变高。要么接受（对局变短），要么按境界限制可带招数（比如一次最多 8 门），后者是规则改动，得单独评审。
- **AI 选择**：`battle.ts` 的 `chooseAction` 是按场景写的硬编码条件，新招各要一条触发条件，否则永远不选。
- **对照表**：`battle-testkit.ts` 的 `Y0_SKILL_IDS` 是旧内容回归用的固定清单，新招不要塞进去。
- **图鉴文案**：`SKILLS` 的 `name` + 图鉴描述；致敬出处置信区写「梦中得授：另界的……」，不做「某某动画」的硬引用。
- **名帖兼容**：旧版本对端收到不认识的技能 id 会怎样，要先写一条测试确认，再决定要不要在握手时过滤。
