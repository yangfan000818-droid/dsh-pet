## 3. 动作素材的提示词

通用前缀照 `prompts/桌面宠物 战斗与修炼动作提示词.md` 的「通用前缀」原样用（Q 版蓝发鲸鱼女仆、绿幕、固定镜头、朝左、离边缘 10%、首尾帧同一姿势等），并保留下面的约束：

- 表情阴沉冷漠、眼神发直，不要微笑卖萌。
- 服装完整、不露腰腹。
- 特效与道具一律二维平涂、实心色块加深色描边，**不要发光、光晕、烟雾、模糊拖影**；不要用绿色。
- 首帧与末帧都和待机首帧一致；**动作素材里不要画光柱、光束、浪头本身**（这些交给贴图），人物手里可以有水球这类小道具。

各段的具体动作：

1. **出手-聚气**：0~0.5 秒标准站立；0.5~1.2 秒双手收向右侧腰际、掌心相对；1.2~2.8 秒掌间凝出一颗蓝白色水球，从小到大涨到约胸前大小，水球悬在两掌之间；2.8~3.4 秒保持姿势、身体轻轻发颤；3.4~4 秒收回站姿，水球消散。
2. **出手-鲸派**：0~0.5 秒标准站立；0.5~1.1 秒双掌收到胸前蓄势；1.1~1.8 秒双掌一起向画面左侧推出、手臂伸直；1.8~3.2 秒保持推出姿势；3.2~4 秒收手回站姿。
3. **出手-领域**：0~0.5 秒标准站立；0.5~1.2 秒右手抬到头顶；1.2~2.2 秒掌心朝下、缓缓按到腹前，像把什么东西压进地里；2.2~3.2 秒保持下压姿势、肩背绷紧；3.2~4 秒起身回站姿。
4. **出手-瞬影**：0~0.5 秒标准站立；0.5~1.0 秒身体猛地一晃；1.0~2.0 秒一个半透明、青灰色的自己留在原地，本体向画面左侧踏出半步（仍在原位附近）；2.0~3.2 秒保持侧身姿势，残影慢慢变淡；3.2~4 秒残影消失、本体回站姿。

## 4. 贴图的提示词

`text2image --ratio=1:1（鲸波、黑雾用 16:9）--resolution_type=2k`，纯绿底 `#00FF00`，抠像后按长边裁。

- **鲸息**：一颗蓝白色的水球，椭圆、半透明感用两三种蓝色平涂分层表现，深蓝描边，表面有两条弧形高光；不要发光、不要背景元素、不要地面；居中。
- **鲸波**：一道朝左冲出的横向水浪，浪头在左侧、浪尾在右侧，深蓝描边、青蓝色平涂分层、几粒水珠；不要发光、不要文字；横向铺满画面、四周留空。
- **深渊符阵**：俯视的正圆形符阵，墨黑与暗紫两色，由细线符纹、同心圆和一角残缺的边纹组成，像从地底渗出来的；平涂、不要发光、不要雾气、不要立体透视；居中等比。
- **深渊黑雾**：一层低伏的暗紫色浓雾，边缘是清楚的团块起伏（不要柔软渐变、不要发光），中间厚、四周薄；横向铺满，适合叠在擂台上。

## 5. 抠像与编码

按 `prompts/桌面宠物 战斗与修炼动作提示词.md` 的规范：

- 视频：两把尺子的 alpha（差值带 + 比值带）、去溢色，640×360 / 24fps / VP9 `ALPHA_MODE=1`，首尾帧与待机一致。
- 贴图：抠绿 + 去溢色，清掉面积 < 40px 的碎点、四周 2% 一律透明，按包围盒裁到留 4px，长边缩到要求尺寸；有方向的一律**朝左**。

## 6. 核验与回报
