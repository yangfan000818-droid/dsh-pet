# 对战招式总表（法宝 / 招式表 / 技能）

2026-10-30。按 `src/app/battle.ts` 的实际结算口径整理，对应 `BATTLE_VERSION = 8`。
所有数值都是**结算前**的裸值；实际落地还要过灵力、破势、会心、泡泡护体与切磋收束，见 §0。
招式 / 法宝的演出（动作素材、飞行物、命中特效）在 `battle-show.ts`，不在本文范围。

## 0. 通用结算口径

### 0.1 出手节奏

- 出手间隔 = `100 / (遁速 + 10)` 秒（遁速 10 → 5 秒一手）；开局随机延迟 ×`0.8–1.2`。
- 用「重」的法宝 / 招式出手后，下一手间隔 ×`1.15`。
- 被「迟缓」命中后，下一手往后推 `0.35` 个间隔。
- 一场最多结算 30 手（`MAX_ACTIONS`）；到点没死人按剩余气血比例判，比例相同比遁速。

### 0.2 一次普通攻击（法宝 / 招式表 / 徒手）的判定顺序

1. **瞬影**：挨打方开着瞬影 → 直接闪（连必中、多段都闪）。
2. **墨汁**：出手方被糊着眼，`dodgeRoll ≥ 0.45` 打空（55%）。
3. **闪避**：必中（烟花、银托盘末段、睡着/入梦/飘着、领域、瞬影）跳过；否则按闪避率判定。闪避率 = `min(35%, 身法 × 1.5% + 8% 化鸽遁 + 秘境加成)`。
4. **魂影**：必中打本体；否则由魂影替掉一层（鬼眼无视魂影）。
5. **水母分身**：10%（`counterRoll ≥ 0.9`）打在分身上；鬼眼看穿。
6. **替挡**：挨打的前 N 下整下替掉，不掉血、不耗泡泡、不判反击。
7. **伤害**：区间随机 + 灵力/破势加成（多段按段数分摊），再过会心、背水、反弹、蓄力减伤、泡泡护体、假死遁。
8. **附带效果**：迟缓、定身；随后判第六感反击、连击、灵兽。

### 0.3 伤害公式

每一段：

```
每段伤害 = rand(最小, 最大) + floor((灵力 × 0.75 + 对方气血上限 × 0.25) / 段数)
```

- 多段法宝 / 招式整段出手合计只吃**一份**灵力与破势，按段数平摊，不会打三段就吃三倍。
- **会心**：基础 8%，带「会心一击」18%，伤害 ×2。
- **背水一战**（秘境加持）：气血低于三成时伤害乘 mods 给的倍率（不传即 ×1）。
- **降龙十八掌后劲**：下一次法宝 / 徒手的第一段打中时 +`10 + floor(灵力 × 0.25)`，打空即作废。
- **泡泡护体**：挡伤后按 ×0.78（向下取整），每场 2 次。
- **鲸派气功蓄力**：挨打先 ×0.7，再走泡泡。
- **切磋 / 隔空**（`FightOptions.damageScale / maxHitShare`）：全伤害 ×0.65，单次最多打掉目标上限的 30%；历练、心魔、渡劫按全额。
- **主动技能**不走上面的攻击判定，直接用公式结算（不判闪避、不会心、不连击）；它们的公式在各条目里单列，同样吃灵力、破势、泡泡、假死与切磋收束。

### 0.4 连击 / 定身 / 迟缓

- **连击**：最后一段打完后判一次，几率 = `min(30%, 身法 × 1%) + 法宝连击加成 + 15%（无影手）`，最多再补 2 段（每段独立判闪避等）。
- **定身**（陀螺晕、雪球/寒气冻）：命中且没被弹回 / 魂影替掉时，按几率让对方**跳过下一次出手**（一拍）。
  刚被控住、还没出手的一方**免疫新的控制**（不能连控成锁）。
- **迟缓**（鸡毛掸子）：命中即生效，不吃几率，对方下一手延后 0.35 个间隔。

### 0.5 控制类技能的共同规则

狮子吼 / 鲸歌 / 魂牵梦绕 / 送友风的控：

```
几率 = clamp(基础几率 + (我方灵力 − 对方身法) × 2%, 25%, 85%)
```

- 基础几率：狮子吼 60%、鲸歌 75%、魂牵梦绕 55%、送友风 65%。
- 伤害被逆流护身印弹回、被魂影替掉、或对方已死时不再判控。
- 对方「刚被控、还没出手」时控不住；没控住会出 `resisted` 事件（狮子吼 / 鲸歌 / 魂牵梦绕 / 送友风都会先造成伤害，白放也不至于空手）。
- 睡着 / 入梦 / 飘着期间，挨到的攻击**一律不判闪避**。

### 0.6 一场一次的主动技能

23 门主动技能每场最多用一次（用过的不会再出现在可选动作里）。鬼手 / 万我大手印封住的「下一手不能放主动招式」只持续一手，那一手按空手结算，技能本身不消耗。

## 3. 主动技能（23 门）

数值格式：`基数 + 灵力项 + 破势项`，其中破势项 = `floor(对方气血上限 × 0.25 × 占比)`。

### 3.1 回复与增益

**凭空生花（bloom）**

- 回复 `ceil(上限 × 18%)` 气血（不超上限），**立刻再出一手**。
- 渡劫里也生效：两道雷之间气血低于一半会自动放一次。

**万我（myriad-self）**

- 分出 **3 重魂影**。之后挨到的普通攻击由魂影替掉一层（必中打本体）；切磋里必中 / 主动招式也能被魂影替（「鬼眼」无视）。
- 魂影只挡攻击，不挡领域暗流、鬼敲门、反击、灵兽、天雷。

**逆流护身印（reverse-seal）**

- 撑起 **1 次**反弹：接下来挨到的**第一次主动出手伤害**（法宝、徒手、主动招式、招式表招式）按 **70%**（向下取整）弹回攻击方。
- 弹回去的那一下不再判闪避 / 魂影 / 分身 / 替挡 / 反击，也不会触发攻击方的护身印（只反一层，防套娃）。
- 反击、灵兽、古人补击、鬼敲门、领域暗流、天雷**不触发**反弹。

**前有古人（ancients）**

- 下一次**真正出手**时，古人先补一击 **80 点**（必中，直接走伤害结算，不吃护身印）。
- 切磋里这一击也能被魂影替（鬼眼除外）。被控跳过的那一拍不消耗，记号一直挂着。

### 3.2 控制

**狮子吼（lion-roar）**

- 伤害 `22 + floor(对方上限 × 0.15)`（不带灵力）；60% 基础几率晕住，跳过下一手。

**鲸歌（whale-song）**

- 伤害 `16 + floor(灵力 × 0.45) + floor(对方上限 × 0.075)`；75% 基础几率哄睡（跳过下一手，睡着时挨打不判闪避）。
- **没哄睡也不白放**：对方下一手延后 0.35 个间隔（被弹回 / 被魂影替掉则没有）。

**魂牵梦绕（dream-chant）**

- 伤害 `14 + floor(灵力 × 0.75) + floor(对方上限 × 0.125)`；55% 基础几率入梦（跳过下一手，入梦时挨打不判闪避）。

**送友风（farewell-wind）**

- 伤害 `18 + floor(灵力 × 0.75) + floor(对方上限 × 0.1)`；65% 基础几率把对方吹得飘起来（跳过下一手，飘着时挨打不判闪避）。
- 只在**串门切磋**里另有一次「送走」判定：命中后 30% 直接结束战斗，按送走判胜（`reason: farewell`）。

**墨汁喷射（ink）**

- 不造成伤害；让对方接下来 **3 次出手**被糊着眼，每次普通攻击 55% 打空（主动招式不受影响，但也会消耗一次）。
- 带「鬼眼」的一方糊不上；「吃苦吃亏」可以清掉自己身上的墨汁。

### 3.3 纯伤害

**蓝鲸现世（blue-whale）**

- 伤害 `34 + 灵力 + floor(对方上限 × 0.25)`（灵力吃整份，不是 0.75）。切磋里整体再 ×0.75。
- 一击约等于满额法宝的 1.5–2 倍，是整套招里最重的一手。

**鲸吞（whale-gulp）**

- 伤害 `18 + floor(灵力 × 0.75) + floor(对方上限 × 0.125)`；回复**实际造成伤害的一半**（不超上限，泡泡挡掉的部分不算）。

**五指拳心剑（finger-sword）**

- 伤害 `22 + floor(灵力 × 0.75) + floor(对方上限 × 0.2)`；**穿护体**：不消耗对方的泡泡、也不打 0.78 折扣。

**降龙十八掌（dragon-palm）**

- 伤害 `28 + floor(灵力 × 0.75) + floor(对方上限 × 0.15)`；打完挂上「亢龙有悔」后劲。
- 后劲：下一次**法宝 / 徒手**的第一段打中时额外 +`10 + floor(灵力 × 0.25)`；打空、被闪、魂影、替挡都算没打中，直接作废。招式表招式和其他主动技能不消耗后劲。

**鬼血（ghost-blood）**

- 伤害 `50 + floor(灵力 × 0.75) + 4 × 对方身上的被动数`（被动越多咬得越狠）。

**无头鬼影（headless-shadow）**

- 伤害 `30 + floor(灵力 × 0.5) + floor(对方上限 × 0.1)`；这一下打死的，**假死遁救不回来**（首级已失）。

**吃苦吃亏（eat-hardship）**

- 顺手清掉自己身上的墨汁；然后按对方身上的东西吃：
  - 有泡泡 → 吃掉一层，回复 `上限 × 15%`；
  - 否则有魂影 → 吃掉一层，回复 `上限 × 12%`；
  - 都没有 → 咬一口 `40 + floor(灵力 × 0.4)`，回复实际伤害的一半。

### 3.4 封印与延迟

**万我大手印（myriad-palm）**

- 伤害 `26 + floor(灵力 × 0.75) + floor(对方上限 × 0.125)`；命中后封住对方**下一手**的法宝（只能空手、放技能或出招）。

**鬼手（ghost-hand）**

- 伤害 `38 + floor(灵力 × 0.75) + floor(对方上限 × 0.1)`；命中后封住对方**下一手**的主动技能（法宝、徒手、招式表招式照常）。

**鬼敲门（ghost-knock）**

- 施放本身无伤害，只给对方挂上敲门声：对方下一次**真正出手前**先挨 `60 + floor(对方上限 × 0.125)` 一下（泡泡照挡、可能触发假死遁）。
- 被控跳过的那一拍不算真正出手，记号一直挂着。

**鬼画（ghost-painting）**

- 随机封住对方一门**被动**，本场失效；封到「泡泡护体」立即清空剩余泡泡，封到「灵兽助阵」立即清空剩余次数。
- 对方没有被动可封时改为直接伤害 `77 + floor(灵力 × 0.75)`。

### 3.5 X25：蓄力 / 领域 / 瞬影

**鲸派气功（tide-cannon）**

- 第一拍只**聚气**，不造成伤害；蓄力期间自己挨到的任何伤害 ×0.7（泡泡在这之后再挡）。被控跳过时蓄力与减伤都保留。
- 下一次**真正出手**时自动放出，不再听决策：伤害 `58 + floor(灵力 × 0.75) + floor(对方上限 × 0.15)`。
- 释放必中，且直接结算：不判闪避、不吃魂影 / 替挡 / 护身印反弹，泡泡护体照挡。蓄力期间被打死就没有释放。

**深渊领域（abyss-field）**

- 展开后持续 **3 次自己的攻击**：期间自己打出的普通攻击**必中**（不判闪避，魂影也替不了）。
- 对方每次**真正出手前**先吃 **15 点**暗流（泡泡照挡、可能触发假死遁；被控跳过不算）。
- 自己每打完一次攻击少一层；放回血 / 封印这类非攻击技能、或被控跳过都不消耗。领域不叠加。

**瞬影（shadow-step）**

- 挨到的**普通攻击**（法宝、招式表、徒手，含多段、含必中）和**灵兽**那一口全部按闪避处理，不掉血、不消耗泡泡 / 魂影 / 替挡；不会因挨打消失。
- 自己**下一次攻击**必中，这一手打完即散；放非攻击技能不解散。
- 主动技能不判闪避，瞬影挡不住主动技能；反击与天雷也照常结算。

## 4. 被动技能（9 门）

**假死遁（play-dead）**

- 每场一次：受到致命伤害时留 1 点气血活下来，但要**躺一拍**（下一次出手跳过，`sham`）。
- 对任何走伤害结算的伤害都生效（含反击、天雷、领域、鬼敲门），除了无头鬼影的「取首级」。

**化鸽遁（dove）**

- 闪避率 +8%（与身法加成合并后仍受 35% 上限约束）。

**泡泡护体（bubble）**

- 每场 2 次：每次挨打挡掉 22% 伤害（留下的比例为 0.78），任何走伤害结算的伤害都能挡，包括反击、天雷、领域、鬼敲门。
- 五指拳心剑穿护体（不消耗、不打折）；被鬼画封掉时剩余次数立即清零。

**第六感（sixth-sense）**

- 挨到**非远程**的普通攻击命中后，45% 反击：伤害 `rand(3,6) + floor(灵力 × 0.75)`，走正常伤害结算（会被泡泡挡、可能触发假死，但不触发护身印反弹）。
- 远程攻击（水枪、弹弓、月刃等）、灵兽、反击本身都不会被反击；被弹回 / 被魂影替掉的那一下也不招反击。

**无影手（shadow-fists）**

- 连击率 +15%。

**会心一击（critical）**

- 会心率从 8% 提到 18%（只影响普通攻击，主动技能不会心）。

**灵兽助阵（spirit-beast）**

- 每场 3 次：自己每次**普通攻击**（法宝 / 招式表 / 徒手，不含主动技能）之后，灵兽追加一口 `4–7` 点。
- 这一口可被闪避（睡着时必中）、不被反击、也不吃护身印；瞬影能闪掉；泡泡照挡。

**水母分身（jelly-clone）**

- 每次挨普通攻击时 10% 由分身替挨（不掉血、不耗泡泡、不判反击）；必中打本体。
- 带「鬼眼」的对手看穿分身与魂影。

**鬼眼（ghost-eye）**

- 自己打出的攻击**无视对方的魂影**（切磋里的必中 / 主动招式也一样）；对方的「水母分身」也骗不到自己；「墨汁喷射」糊不上自己。
- 不提供直接数值，克制的是魂影、分身、墨汁三套。

## 6. 渡劫与心魔

- **渡劫**：N 道天雷依次劈下，单道伤害与境界、雷数、自身气血挂钩；每道可闪（按一半闪避率）、可被泡泡挡、可触发假死遁；两道雷之间气血低于一半会自动「凭空生花」。其他主动技能用不上。
- **心魔**：复制自己的气血 / 灵力 / 身法 / 遁速 ×0.9（向下取整，最低 1），法宝与技能照抄，按普通对战结算。
