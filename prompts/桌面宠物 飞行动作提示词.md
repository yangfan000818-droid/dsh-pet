# 桌宠飞行动作提示词

移动池「飞来飞去」用的 5 秒素材（`assets/webm/飞来飞去.webm`）。绿幕规范、抠像参数与检查方法
同 `桌面宠物 战斗与修炼动作提示词.md`，这里只记本条的首尾帧、生成命令和提示词。

## 规格

- 时长 5 秒，1280×720，24fps，`seedance2.0mini` + `--video_resolution=720p`。
- 首尾帧都是「待机呼吸休闲」首帧垫绿底（同一张图同时当 first / last），保证换回待机时不跳。
- 角色全程不横向 / 纵向平移；只在原地完成「起飞 → 滑翔悬停 → 落地」，位移由播放端的窗口移动提供。

## 生成

```sh
# 首尾帧（在仓库根；macOS 的 ffmpeg 需要显式 -c:v libvpx-vp9 才能解出 webm 的 alpha）
ffmpeg -y -c:v libvpx-vp9 -i "assets/webm/待机呼吸休闲.webm" -frames:v 1 -pix_fmt rgba /tmp/idle-rgba.png
ffmpeg -y -f lavfi -i color=c=0x00FF00:s=1280x720 -i /tmp/idle-rgba.png \
  -filter_complex "[1:v]scale=1280:720:flags=lanczos,format=rgba[p];[0:v][p]overlay=format=auto" \
  -frames:v 1 /tmp/idle-green.png

dreamina frames2video --first=/tmp/idle-green.png --last=/tmp/idle-green.png \
  --model_version=seedance2.0mini --video_resolution=720p --duration=5 \
  --prompt="<下面这段>" --poll=240
```

抠像：

```sh
D="(g(X,Y)-max(r(X,Y),b(X,Y)))"
AD="clip((130-$D)/80,0,1)"
AQ="if(gte(g(X,Y),70),clip((0.7-$D/g(X,Y))/0.25,0,1),1)"
ffmpeg -i 生成.mp4 -an -vf "fps=24,scale=640:360:flags=lanczos,format=rgba,\
geq=r='r(X,Y)':g='min(g(X,Y),max(r(X,Y),b(X,Y)))':b='b(X,Y)':\
a='st(0,255*min($AD,$AQ));if(lt(ld(0),20),0,ld(0))',format=yuva420p" \
  -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 32 -auto-alt-ref 0 \
  -metadata:s:v:0 alpha_mode=1 "assets/webm/飞来飞去.webm"
```

## 提示词

> 【无字幕】画面里没有任何文字、字幕、数字或 logo。镜头固定不动，不推拉不摇移。视频比例 16:9，背景是纯绿幕色 #00FF00，单一纯色，没有阴影、地面、渐变或杂物。角色就是首帧里的 Q 版蓝发鲸鱼女仆：保持同一张脸、同样的长蓝发和呆毛、白色荷叶边头饰、耳侧鳍饰、深蓝女仆裙和印着小鲸鱼的白围裙、身后的鲸鱼尾巴，2D 赛璐璐画风与首帧一致。人物大小和位置与首帧完全一致，身体始终保持在画面中央，不向左/右/上/下平移；任何身体部位都离画幅边缘至少 10%，不出画、不被裁切。0~0.5秒：标准正面站立，与首帧一致。0.5~1.2秒：微微屈膝蓄力，随即双臂向两侧平展开像滑翔，双脚离开地面向后收起，裙摆、长发和鲸鱼尾巴向上飘起，表情变得开心。1.2~4.0秒：保持轻盈的滑翔悬停姿态，身体像在水中一样上下极小幅浮动（幅度不超过画幅高度的 2%），手臂平展，长发、裙边和鲸鱼尾巴持续柔和飘动，眼睛亮晶晶。4.0~5.0秒：双脚轻轻落回原地，手臂放下，恢复与首帧完全一致的标准正面站立。第一帧和最后一帧都是首帧那样的标准正面站立，结尾没有任何特效残留。全程没有道具、没有特效、没有光点、没有光晕、没有烟雾、没有拖影。绿色背景的亮度和颜色从头到尾保持不变，不变暗、不闪烁。角色身上不使用绿色。

## 检查

- 首帧包围盒应与待机一致（640×360 下约 x 212–427、y 61–332）；滑翔时手臂展开到 x 116–511，
  仍应完整留在画幅内。
- 在深色、浅色桌面上各看一遍：绿边、灰雾和背景压暗都不合格。
- 素材自带几颗小气泡（模型自行加的），属于飞行点缀；如果以后重做时出现大面积灰点，按战斗素材
  的「只留身体连通块 + 面积阈值」清理。
