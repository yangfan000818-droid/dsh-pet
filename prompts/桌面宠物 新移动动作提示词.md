# 桌宠新移动动作提示词

移动池新增的 12 套素材（`assets/webm/`）。绿幕规范、首尾帧、抠像与检查方法同
`prompts/桌面宠物 飞行动作提示词.md`，这里只记每条的动作设计、原著依据和生成命令。

## 规格

- 地面移动：10 秒，1280×720，24fps，`seedance2.0mini` + `--video_resolution=720p`。
- 飞行移动：5 秒，参数同上。
- 瞬移（遁地 / 地狼蛛遁地）：5 秒；定仙游复用现有 4 秒 `秘境-定仙游.webm`，不重出。
- 首尾帧都是「待机呼吸休闲」首帧垫绿底（同一张图同时当 first / last），保证换回待机时不跳。
- 角色全程不横向 / 纵向平移；位移由播放端的窗口移动提供。
- 朝向：素材按「面向画面左侧」画；渲染端面向右时整段 `scaleX(-1)` 镜像。

## 原著依据

- **定仙游**（《蛊真人》）：宇道六转仙蛊，由神游蛊、碧空蛊、定星蛊借太古荣耀之光合炼；
  「三息之内，能带人走到心中想去的地方」，目的地必须心里有清晰印象，地点大变则失败。
  原著里它**不能传送体外衣物**（方源传送到狐仙福地时衣裤留在原地，是书里的名场面）。
  现有 `秘境-定仙游.webm` 已按「碧绿蝴蝶、碧芒一闪、人消失、原地重现」做过，直接复用为瞬移动作。
- **千里地狼蛛**（《蛊真人》）：五转坐骑类蛊虫，通体漆黑、泛金属光泽，三对触脚尖端呈螺旋形，
  能「钻土地遁，可快速潜行于地底」。原著里**没有「遁地蛊」**，所以通用「遁地」不挂原著名，
  另做一套「地狼蛛遁地」忠于原著。
- **御剑飞行**：通用仙侠意象，不绑定具体作品。
- **骑鲸飞行**：古典「骑鲸」意象（李白骑鲸捉月），不绑定具体作品；和鲸鱼女仆的人设最搭。

## 通用前缀

> 【无字幕】画面里没有任何文字、字幕、数字或 logo。镜头固定不动，不推拉不摇移。视频比例 16:9，背景是纯绿幕色 #00FF00，单一纯色，没有阴影、地面、渐变或杂物。角色就是首帧里的 Q 版蓝发鲸鱼女仆：保持同一张脸、同样的长蓝发和呆毛、白色荷叶边头饰、耳侧鳍饰、深蓝女仆裙和印着小鲸鱼的白围裙、身后的鲸鱼尾巴，2D 赛璐璐画风与首帧一致。人物大小和位置与首帧完全一致，身体始终保持在画面中央，不向左/右/上/下平移；任何身体部位（含呆毛、鳍饰、裙摆、尾巴、手脚、道具）都离画幅边缘至少 10%，不出画、不被裁切。第一帧和最后一帧都是与首帧完全一致的标准正面站立，结尾没有任何道具或特效残留。绿色背景的亮度和颜色从头到尾保持不变，不变暗、不闪烁。角色身上不使用绿色。

## 动作提示词

### 跳着走（10 秒）

> 0~0.5秒：与首帧一致的标准正面站立。0.5~1.2秒：身体原地转向画面左侧，屈膝蓄力，双臂向后摆。1.2~8.8秒：保持身体朝向画面左侧，连续做轻快的双脚并拢跳跃前进动作：每次下蹲蓄力后双脚同时离地跳起约画幅高度的 12%，双手随节奏前后摆动，长发、裙摆和鲸鱼尾巴上下弹动；落地时膝盖弯曲缓冲，立刻接下一次起跳，约每 0.6 秒跳一次；身体中心始终固定在画面中央，不向左/右漂移，每次落地都回到同一位置，脚不滑出画面。8.8~10秒：最后一次落地，转回正面，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、光点、烟尘或拖影。

### 咕噜咕噜滚动（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：下蹲抱膝，把头、手臂和鲸鱼尾巴收进身体，卷成一个圆滚滚的球，球上仍能看到蓝色长发、白色荷叶边和鲸鱼尾巴的花纹。1.5~8.8秒：这个球以身体中心为轴，向画面左侧滚动，像轮子一样原地旋转（从正面看是逆时针），连续滚 2~3 圈；球心始终固定在画面中央，不向左/右移动；滚动时裙摆和头发随旋转轻微飘动，每次触地有极轻微的压扁回弹。8.8~10秒：球停止旋转，张开身体，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、光点、烟尘或拖影。

### 小碎步快跑（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.2秒：身体微微前倾并转向画面左侧，双臂弯曲，重心前移。1.2~8.8秒：保持朝向画面左侧，做快速细碎的小步跑：双脚交替快速点地，步幅很小，膝盖交替抬起，双臂前后快速摆动，长发、裙摆和鲸鱼尾巴向后飘；身体上下轻微起伏，但中心始终固定在画面中央，不向左/右漂移。8.8~10秒：逐渐减速，转回正面，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、光点、烟尘或拖影。

### 侧身滑步（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：身体完整转向画面左侧，呈侧身姿态，一只脚向前、双臂向两侧平展保持平衡。1.5~8.8秒：保持侧身，像在冰面上一样向画面左侧平滑滑行：前后脚交替蹬地，身体随节奏轻微起伏和左右摇摆，裙摆、长发和鲸鱼尾巴向后飘动；身体中心始终固定在画面中央，不向左/右移动，脚每次蹬完都滑回原位；滑行动作流畅、没有摩擦感、没有停顿。8.8~10秒：停止滑行，转回正面，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、光点、烟尘或拖影。

### 御剑飞行（5 秒）

> 0~0.5秒：标准正面站立。0.5~1.0秒：一柄青蓝色飞剑从脚下由虚到实凝聚出现，角色轻轻跳上剑身，双脚一前一后站稳，身体微微前倾。1.0~4.2秒：保持御剑姿态向画面左侧滑翔：飞剑悬在脚下，剑身发出淡淡的青色光芒（光芒贴住剑身，不要大面积光晕），长发、裙摆和鲸鱼尾巴向后飘；身体像在水中一样上下极小幅浮动（幅度不超过画幅高度的 2%）；身体中心始终固定在画面中央，不向左/右平移。4.2~5.0秒：飞剑缓缓落到脚下，角色跳下，飞剑由实到虚消散，恢复与首帧完全一致的标准正面站立，结尾没有剑或光效残留。全程没有其他道具、文字、烟尘或拖影。

### 骑鲸飞行（5 秒）

> 0~0.5秒：标准正面站立。0.5~1.2秒：一头 Q 版小蓝鲸从角色身后由虚到实浮现，角色侧身跨坐在鲸背上，双手扶住鲸背，鲸鱼悬浮在脚下。1.2~4.2秒：小蓝鲸驮着角色向画面左侧平稳飞行：鲸尾上下摆动，喷出几颗小水泡（水泡是小点缀，不要大面积），长发、裙摆和鲸鱼尾巴向后飘；角色保持坐姿微笑；身体中心始终固定在画面中央，不向左/右平移。4.2~5.0秒：小蓝鲸缓缓下降，角色下鲸，小蓝鲸由实到虚消散，恢复与首帧完全一致的标准正面站立，结尾没有鲸鱼、水泡或光效残留。全程没有其他道具、文字、烟尘或拖影。

### 骑自行车（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：一辆 Q 版复古自行车从角色身前由虚到实出现，角色跨上车座，双手握住车把，双脚踩上踏板。1.5~8.8秒：角色骑着自行车向画面左侧前进：双脚交替踩踏板，车轮持续转动，身体随踩踏节奏轻微左右摆动，长发、裙摆和鲸鱼尾巴向后飘；自行车和角色整体保持在画面中央，不向左/右平移（车轮原地转动）；表情开心。8.8~10秒：自行车减速停下，角色下车，自行车由实到虚消散，恢复与首帧完全一致的标准正面站立，结尾没有自行车残留。全程没有其他道具、文字、烟尘或拖影。

### 滑板（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：一块 Q 版滑板从角色脚下由虚到实出现，角色侧身站上滑板，双脚一前一后，膝盖微屈。1.5~8.8秒：角色踩着滑板向画面左侧滑行：身体随滑行左右摇摆，双臂张开保持平衡，滑板前后轻微翘动，长发、裙摆和鲸鱼尾巴向后飘；身体中心始终固定在画面中央，不向左/右平移；表情轻松得意。8.8~10秒：滑板减速停下，角色跳下滑板，滑板由实到虚消散，恢复与首帧完全一致的标准正面站立，结尾没有滑板残留。全程没有其他道具、文字、烟尘或拖影。

### 太空步（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：身体转向画面左侧，微微低头，双臂自然下垂，摆出迈克尔·杰克逊式的太空步起势。1.5~8.8秒：保持朝向画面左侧，做经典太空步：一只脚用脚尖向后滑，另一只脚交替支撑，身体像在向后滑行却始终保持在画面中央；双臂随节奏摆动，长发、裙摆和鲸鱼尾巴轻轻晃动；动作流畅、有节奏感；身体中心不向左/右漂移。8.8~10秒：停止滑步，转回正面，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、光点、烟尘或拖影。

### 凌波微步（10 秒）

> 0~0.5秒：标准正面站立。0.5~1.5秒：身体转向画面左侧，双臂轻盈展开，脚尖点地，摆出轻功起势。1.5~8.8秒：保持侧身，向画面左侧做凌波微步式的轻快横移：脚尖交替轻点地面，步伐轻盈连贯，身体像在水面上滑行，裙摆、长发和鲸鱼尾巴柔和飘动；脚每次点地都不发出声响，身体中心始终固定在画面中央，不向左/右平移。8.8~10秒：收势，转回正面，恢复与首帧完全一致的标准正面站立。全程没有道具、特效、水花、光点、烟尘或拖影。

### 遁地（5 秒，瞬移）

> 0~0.5秒：标准正面站立。0.5~1.5秒：角色低头看向地面，脚下出现一圈淡淡的土黄色光纹（贴地、不要大面积），身体开始向下沉。1.5~2.2秒：角色像沉入水面一样向下钻入地面，身体从脚到头逐渐消失，最后只剩几颗小土粒和光点，画面变回纯绿幕。2.2~3.6秒：画面保持纯绿幕，没有任何角色或残留（这段用于传送）。3.6~4.3秒：角色从地面下由头到脚缓缓升起，土黄色光纹再次出现。4.3~5.0秒：光纹消散，恢复与首帧完全一致的标准正面站立，结尾没有任何特效残留。全程镜头固定，角色和特效都在画面中央，不向左/右平移；没有文字、大面积烟尘或拖影。

### 地狼蛛遁地（5 秒，瞬移）

> 0~0.5秒：标准正面站立。0.5~1.5秒：地面裂开，一只通体漆黑、泛着金属光泽的巨型蜘蛛从地下钻出——它有三对螺旋尖足的触脚，体型比角色大一圈，动作沉稳。角色侧身跨上蛛背，双手扶住。1.5~2.5秒：地狼蛛驮着角色向下钻入地面，蛛身和角色从脚到头逐渐没入土中，最后只剩几颗土粒，画面变回纯绿幕。2.5~3.6秒：画面保持纯绿幕，没有任何角色、蜘蛛或残留（这段用于传送）。3.6~4.5秒：地狼蛛驮着角色从地下由头到脚升起，土粒落下。4.5~5.0秒：角色跳下蛛背，地狼蛛钻回地下消失，恢复与首帧完全一致的标准正面站立，结尾没有蜘蛛、土粒或特效残留。全程镜头固定，角色与蜘蛛都在画面中央，不向左/右平移；没有文字、大面积烟尘或拖影。

## 生成

首尾帧（在仓库根；macOS 的 ffmpeg 需要显式 `-c:v libvpx-vp9` 才能解出 webm 的 alpha）：

```sh
ffmpeg -y -c:v libvpx-vp9 -i "assets/webm/待机呼吸休闲.webm" -frames:v 1 -pix_fmt rgba /tmp/idle-rgba.png
ffmpeg -y -f lavfi -i color=c=0x00FF00:s=1280x720 -i /tmp/idle-rgba.png \
  -filter_complex "[1:v]scale=1280:720:flags=lanczos,format=rgba[p];[0:v][p]overlay=format=auto" \
  -frames:v 1 /tmp/idle-green.png
```

每条动作（提示词 = 通用前缀 + 对应段落）：

```sh
dreamina frames2video --first=/tmp/idle-green.png --last=/tmp/idle-green.png \
  --model_version=seedance2.0mini --video_resolution=720p --duration=<5 或 10> \
  --prompt="<通用前缀 + 对应段落>" --poll=240
```

抠像（与飞行动作同一条，输出 640×360 播放格式）：

```sh
D="(g(X,Y)-max(r(X,Y),b(X,Y)))"
AD="clip((130-$D)/80,0,1)"
AQ="if(gte(g(X,Y),70),clip((0.7-$D/g(X,Y))/0.25,0,1),1)"
ffmpeg -i 生成.mp4 -an -vf "fps=24,scale=640:360:flags=lanczos,format=rgba,\
geq=r='r(X,Y)':g='min(g(X,Y),max(r(X,Y),b(X,Y)))':b='b(X,Y)':\
a='st(0,255*min($AD,$AQ));if(lt(ld(0),20),0,ld(0))',format=yuva420p" \
  -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 32 -auto-alt-ref 0 \
  -metadata:s:v:0 alpha_mode=1 "assets/webm/<动作名>.webm"
```

瞬移动作的「空画面」段要逐帧确认：如果模型没留干净，抠像后把该段 alpha 清零，
再把 `teleportAt` 对到消失时刻：定仙游约 2.5 秒 / 4 秒（0.625）；遁地约 2.75 秒 / 5 秒（0.55，
第 66–73 帧清零）；地狼蛛遁地约 2.4 秒 / 5 秒（0.48，素材自带 2.38–3.12 秒的干净空画面）。

## 成片备注（2026-11）

- 骑鲸飞行、滑板、骑自行车首版都把道具 / 速度特效画到了画幅边缘（鲸鱼底部、滑板气流、自行车灰烟
  被窗口边界平切），用「构图硬约束 + 特效禁令」重出：骑鲸、滑板采用重出版本；御剑保留首版
  （实体剑完整，只有半透明剑光贴右边缘）。
- 遁地首版消失段残留土黄色光纹，清空第 66–73 帧 alpha 后重编。

## 检查

- 首帧包围盒与待机一致（640×360 下约 x 212–427、y 61–332）。
- 在深色、浅色桌面上各看一遍：绿边、灰雾和背景压暗都不合格。
- 道具（剑、鲸、自行车、滑板、蜘蛛）首尾帧不能残留，且不能压到角色身体或被画幅裁切。
- 瞬移素材的消失段必须没有任何不透明像素，传送时窗口才敢跳。
